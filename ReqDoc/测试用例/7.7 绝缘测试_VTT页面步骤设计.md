# 绝缘测试：VTT 页面步骤设计（待确认）

依据《原始需求文档》7.7：样件不接线束，室温换气 0.5 h（湿热测试后）、直流 500 V 保持 60 s；每个适用绝缘测试点全程电阻 >10 MΩ 且样件无损坏。本文件只做页面设计，不修改工程。

## 资源核查

| 类别 | 已核实资源及限制 |
|---|---|
| 固定模板 | 现有 VTT Sequence Preparation 标题“准备测试环境”调用 `PHASE_Prepare(string SequenceName)`，内部控制台架继电器/电源/LIN；Completion 标题“完成测试并恢复安全态”调用 `PHASE_Complete()`。两者不能据此证明外部 500 V 仪器已放电、测试线已拆除。 |
| Test Case / Sequence | `SleepCurrent`、`WorkCurrent` 测电流；`VoltageAccuracyGroup` 测工作电压；无断开线束、500 V 绝缘测量、换点和高压放电确认 Test Case；不复用不相干封装。 |
| CAPL 函数 | 已核实 `export testfunction PWR_Configure_Check(float V,float Ichg,float Idchg)`、`PWR_Off_Check()`、`LIN_Stop_Check()`；电源设压仅限 8～15.5 V，这些节点不能用于 500 V 绝缘测试或作为物理断线束证据。 |
| 参数及系统变量 | `IBS_Case`：`IBS::TB_BatteryMin_V=8.0`、`IBS::TB_BatteryMax_V=15.5`、`IBS::TB_MaxSwitchVoltage_V=1.0`；`IBS_Reuse`：`IBS::TB_DvmZeroTolerance_V=1.0`。`.can` 已引用 `@sysvar::N8361::DVM_Voltage`、`Set_OutputSts`、`@sysvar::Power_RelayCrtl::BatteryConnectEquipment`、`CAB1500_PowerCtrl`、`IBS_PowerCtrl`；没有绝缘仪电压/电阻/放电状态系统变量。 |

## 页面四列步骤（所有高压操作暂停，不能执行）

| Command | Caption（页面显示的中文） | 调用对象 | 封装 |
|---|---|---|---|
| Preparation | 准备测试环境 | 暂不调用 `PHASE_Prepare`：其 IDLE 继电器/台架电源准备与“样件未连接线束”条件是否兼容未确认 | 现有 Test Table Function，当前试验不适用性待核实；不可伪称已完成脱线束 |
| Test Case | 核验湿热后室温换气至少三十分钟并断开线束 | 湿热记录、换气计时和人工隔离确认均未接入；本步跳过 | 拟新增页面 Test Case，尚不存在；不能用台架继电器替代断开线束 |
| Test Case | 逐个选定适用绝缘测试点并连接绝缘仪 | 绝缘端子间、端子与金属外壳、端子与包金属箔的非金属外壳；真实端子对清单/绝缘仪接线未提供 | 拟新增页面 Test Case，非现有函数；本步跳过 |
| Test Case | 每点施加直流 500 V 保持六十秒并监测绝缘 | 每点测试全程电阻严格 >10 MΩ、无击穿/损伤；仪器控制、数据采样及高压防护接口均缺失 | 拟新增页面 Test Case，非现有接口；本步跳过，现有 `PWR_Configure_Check` 禁用 |
| Test Case | 放电归零后换点并保存各点结果 | 高压放电确认、电阻值、点位标识及记录通道缺失；禁止带电换线 | 拟新增页面 Test Case，尚不存在；本步跳过 |
| Completion | 完成测试并恢复安全态 | 暂不调用 `PHASE_Complete()`，必须先独立确认外部高压源断能及放电完成，且与无连接线束条件相容 | 现有 Test Table Function；不能把其 N8361 DVM 回零解释为绝缘仪 500 V 已放电 |

1. 缺少绝缘电阻仪型号、指令接口、耐压保护、独立放电回读和校准状态；500 V 高压试验未获实际环境支持。所有相关页面封装均为**拟新增非现有接口**。
2. 需确认湿热表 2 测试是否已完成、30 min 换气起止、具体端子对/外壳材质及金属箔适用性、试验中电阻连续观测和损坏判据。
3. 当前台架 Preparation 会操作接线相关节点，与“样件未连接线束”有潜在冲突。未确认离线试验流程之前，不能按模板自动启动或认为 Completion 可覆盖外部高压安全。
