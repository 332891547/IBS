# 瞬时过电压测试：VTT 页面步骤设计（待确认）

依据《原始需求文档》7.12；顺序为短时测试（10 s 内 3 次脉冲），随后寿命测试（1000 次、脉冲间隔 9 s）。样件带载典型工作，要求全过程所有功能和相关输出满足设计范围，试后仍正常。本稿仅供确认页面顺序；**现有电源控制不支持 16～18 V 及毫秒级脉冲，不得运行占位步骤**。

## 资源清单

| 类别 | 实际核实资源和默认值 | 适用边界 |

| GBK 参数 | `IBS_Case::IBS::TB_BatteryMin_V=8.0`、`TB_BatteryMax_V=15.5`；`工作电流测试::IBS::WC_VoltageTimeout_ms=2000`、`WC_VoltageTolerance_V=0.5` | 无 Umin/Ul/Umax、tr/tf、t1/t2、短时/寿命序列参数；2000 ms 到压检测不能验证 1 ms 沿 |

| Command | Caption（页面显示的中文） | 调用对象 | 封装 |
|---|---|---|---|
| Preparation | 准备测试环境 | `PHASE_Prepare("瞬时过电压测试")` | 已有 Test Table Function；固定 Preparation |
| Test Case | 先在 10 s 内执行三次过压脉冲 | **拟新增**“短时三脉冲测试”页面 Test Case；Umin=16 V、Ul（原文步骤写 U1）=17 V、Umax=18 V，tr=tf=1 ms，t1=400 ms、t2=600 ms | 拟新增 Test Case（非现有资源）；发生器与示波器接口尚缺，暂跳过执行 |

## 未决问题与实际环境缺口

1. **硬阻断：**`PWR_Configure` 和 `PWR_On` 在 V>15.5 时拒绝；没有经核实的 16～18 V 脉冲源/同步触发接口，不能直接用 Set 系统变量绕过上限。需要核实源额定、受测负载安全、实际脉冲控制接口和示波器采样/自动留存波形接口。
2. `tr=tf=1 ms` 与 t1=400 ms/t2=600 ms 的具体波形起止定义、Ul 是字母 l 还是数字 1、10 s 内 3 次的确切起点/间距、寿命测试 9 s 间隔是脉冲起点至起点还是脉冲结束至下一次起点都未定义，不能自行补出波形。
3. 1000 次 × 9 s 间隔约需 2.5 h（实际随间隔定义和脉宽变化），原文“每隔一定次数如 100 次观察”与“整个过程所有输出必须验证”不能等同；需明确输出名、每项容差/采样率、异常时停止与留存策略，以及试后功能恢复判据。
4. 固定 Preparation 会停 LIN/关输出，须确认进入带载典型工作模式的可用启动程序；不把 8.5 V 反复上下电 Test Case 用作此过压用例。
