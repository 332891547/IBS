# 跨接起动测试：VTT 页面步骤设计（待确认）

依据《原始需求文档》7.8：典型工作模式下施加 26 V 1 min、恢复常规电压，至少 3 轮；启动相关零件在试验中/后均正常，非启动相关零件允许试验中失效、试验后须自动恢复。只做页面设计，不修改工程。

## 页面四列步骤（高压刺激及功能判据暂跳过）

| Command | Caption（页面显示的中文） | 调用对象 | 封装 |
|---|---|---|---|
| Preparation | 准备测试环境 | `PHASE_Prepare("跨接起动测试")` | 已有 Test Table Function；固定模板原样调用；先确认外部 26 V 源已断能 |
| Test Case | 在典型工作模式下建立常规供电和功能基线 | 常规电压、供电限流、LIN 帧/数据和 IBS 所属零件类别待确认 | 拟新增页面 Test Case，非现有接口；暂不指定 `PWR_Configure_Check` 的未授权限流 |
| Test Case | 每轮施加 26 V 并保持一分钟 | 26 V 独立耐压电源、实际回读和切换互锁均未核实；重复至少三轮 | 拟新增页面 Test Case，尚不存在；此步跳过，现有 N8361 的 `PWR_Configure_Check(26,...)` 会被拒绝 |
| Test Case | 分别记录试验中启动相关和非启动相关功能 | 启动相关必须满足设计；非启动相关允许部分功能暂不满足，但需逐项记录；所属类别和判据未给出 | 拟新增页面 Test Case，非现有接口；本步跳过，不预设 IBS 类别 |
| Test Case | 恢复常规电压并核对每轮功能自动恢复 | 外部源安全切换、恢复后启动相关功能及非启动相关故障自动恢复的测量通道待核实 | 拟新增页面 Test Case，非现有接口；本步跳过，不用关输出代替平稳电压切换 |
| Completion | 完成测试并恢复安全态 | `PHASE_Complete()` | 已有 Test Table Function；固定模板原样调用；外部 26 V 源须独立确认断能 |

## 未决问题与阻断

1. 电源设备 26 V 能力、独立测压、线束保护、隔离切换及高压断能均无证据；现有 `PWR_Configure_Check` 超范围拒绝，不能通过改判据或直接设置 `Set_OutPutVoltage` 绕开。
2. IBS 属“启动相关零件”还是“非启动相关零件”未明确；缺少典型工作模式定义和每项功能在试验中/后的测量指标。两类判据不能同时套在 IBS 上。
3. 需确认常规恢复电压（原文只举 12 V 例）、限流与电压切换期间允许断电与否、三轮之间的间隔及功能恢复时间窗；不能自行定值。
