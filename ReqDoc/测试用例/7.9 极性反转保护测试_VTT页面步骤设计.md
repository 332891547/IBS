# 极性反转保护测试：VTT 页面步骤设计（待确认）

依据《原始需求文档》7.9：初始休眠或典型工作模式，-14 V 反接保持 10 min；不能发生不安全功能，保险丝可以保护动作；断电、拆反接、必要时恢复保护器件后，正向供电应满足功能要求；至少 3 轮。本文件仅为页面伪代码，不修改工程。

## 资源核查

| 类别 | 已核实资源及限制 |
|---|---|
| 固定模板 | VTT 的 Preparation“准备测试环境”调用 `PHASE_Prepare(string SequenceName)`；Completion“完成测试并恢复安全态”调用 `PHASE_Complete()`；现有模板仅管台架电源、LIN、继电器及日志，不控制外部反接设备或接线。 |
| Test Case / Sequence | `SleepCurrent` 测休眠电流；`ResetRepeatedPowerCycle` 测正向 8.5 V 供断电，均不是反接安全试验。不存在 -14 V、保险丝状态和恢复验证的等价 Test Case。 |

| 参数和系统变量 | `IBS_Case`：`IBS::TB_BatteryMin_V=8.0`、`IBS::TB_BatteryMax_V=15.5`、`IBS::TB_MaxSwitchVoltage_V=1.0`；`IBS_Reuse`：`IBS::TB_DvmZeroTolerance_V=1.0`。`.can` 已引用 `@sysvar::N8361::DVM_Voltage`、`Set_OutputSts`、`Set_OutPutVoltage`、`@sysvar::Power_RelayCrtl::BatteryConnectEquipment`、`CAB1500_PowerCtrl`、`IBS_PowerCtrl`；没有反接极性核验、熔丝监测、隔离和外部 -14 V 回读变量。 |

## 页面四列步骤（仅安全流程设计，非执行授权）

| Command | Caption（页面显示的中文） | 调用对象 | 封装 |
|---|---|---|---|
| Preparation | 准备测试环境 | 暂不执行 `PHASE_Prepare`：模板会操作台架继电器，反接接线/隔离未知 | 已有 Test Table Function；原样保留，待确认与反向电源互锁后才能调用 |
| Test Case | 确认休眠或典型工作模式及外部反接隔离 | 目标模式、正向台架完全断开、外部电源断能与极性实测均缺资源 | 拟新增页面 Test Case，不是现有函数；本步跳过，不能仅凭继电器命令确认断开 |
| Test Case | 安全接入 -14 V 并保持十分钟，重复至少三轮 | 反接电源、极性回读、输入电流保护、十分钟保持与回读接口未经核实 | 拟新增页面 Test Case，非现有接口；本步跳过，严禁 `PWR_Configure_Check(-14,...)` 或直接写系统变量 |
| Test Case | 各轮持续观察异常及保护器件动作 | 监测不安全功能、烟/火花等、保险丝动作；缺少人工确认标准和传感/报告接口 | 拟新增页面 Test Case，尚不存在；此步跳过，反接期间**不要求功能正常** |
| Test Case | 断开反向电源、确认失电后恢复正向接线 | 高压/反向电源失电回读、拆反接与熔丝同规格复位的人工作业凭据缺失 | 拟新增页面 Test Case，非现有接口；此步跳过，不允许带电换线或自动复位保险丝 |
| Test Case | 正向重新供电后验证规定功能 | 休眠模式需可唤醒且正常；工作模式功能恢复；每轮功能判据与正向电压待确认 | 拟新增页面 Test Case，尚不存在；不能借 `SleepCurrent` 等价认定全部功能恢复 |
| Completion | 完成测试并恢复安全态 | 暂不调用 `PHASE_Complete()` 处理反向电源；仅在外部反接电源已断能、接线复原并确认模板安全后原样调用 | 已有 Test Table Function；其 DVM 回零不证明反向源断能 |

## 未决问题与阻断

1. -14 V 超出现有设压允许范围，缺少隔离反接电源、极性独立回读、熔丝状态及输入限流/能量保护方案；反接电流路径是否经过 CAB1500、N8361、LIN 等台架设备未明确，存在硬件损伤风险。
2. 休眠和典型工作两种模式都要测还是择一；每种模式执行至少 3 次还是总计 3 次；保险丝更换后能否重复、换线/复位责任人及安全核验记录须确认。
3. 原文“持续供电 10 min”与保险丝可能熔断相冲突：熔断时器件不再持续受电，应明确何时判保护成功及计时是否继续。功能恢复的具体指标和等待窗口尚缺。

验证：只读核查需求、VTT、GBK CAPL 与 GBK 参数；未编译、未做反接试验，工程文件未修改。
