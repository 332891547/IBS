# 6.1 工作电流测试

## 前置条件

工作条件：IBS安装在Vbat电源上；25℃±10℃。

所需设备：带有通讯的程控电源，运行上位机的电脑，不需要真实电池、CANoe。

IBS状态：烧录最新的IBS软件。

平均电流定义：10分钟内电流积分平均数据。

测试范围：VBat范围应该从10V到14V每隔1V测试一个数据点。

## 用例步骤

|序号|操作步骤|预期结果|
| ---- | ---- | ---- |
|1.1|设置电源电参数：将电源电压设置为Vbat|/|

|2.1|开启程控电源的输出|电源电压2S内上升至Vbat|
|3.1|检测LIN报文：检测IBS是否正常通讯|IBS的电压反馈在1S内反馈数据接近Vbat|
|4.1|积分并计算工作电流：清零历史积分参数|/|
|4.2|持续积分10分钟电流数据|/|

# 6.2 SOC自校准功能测试-静置法

## 前置条件

6.2.1 将测试所用的蓄电池处理至满充电状态，充放电方法参照GB/T 5008.1。

6.2.2 读取IBS的SOC及SOC_STATE，SOC_STATE应为未校准状态。

6.2.3 按IBS静置条件进行静置，静置后，读取IBS的SOC及SOC_STATE信号，SOC_STATE应为校准后的状态。

6.2.4 将蓄电池分别处理至0%SOC，10%SOC，20%SOC，30%SOC，…90%SOC等十种状态，重复6.2.2—6.2.3。

## 用例步骤

|序号|操作步骤|预期结果|
| ---- | ---- | ---- |
|1|将测试用蓄电池按GB/T 5008.1规定的充放电方法，处理至满充电状态|蓄电池达到满充电状态|
|2|读取智能电池传感器（IBS）的剩余电量（SOC）及剩余电量状态（SOC_STATE）|SOC_STATE显示为未校准状态|
|3|按IBS静置条件，将蓄电池静置（静置环境、时长等遵循IBS要求），静置后再次读取IBS的SOC及SOC_STATE信号|SOC_STATE显示为校准后的状态|
|4|将蓄电池分别处理至0%SOC、10%SOC、20%SOC、30%SOC、40%SOC、50%SOC、60%SOC、70%SOC、80%SOC、90%SOC状态（可通过充放电等方式精准调整），每次达到对应SOC后，重复步骤2-3|每次对应SOC状态下，先读取到SOC_STATE为未校准状态，静置后SOC_STATE变为校准后状态|

# 6.3 电压精度测试

## 前置条件

6.3.1 将电压表分别接于蓄电池的正负极间，测试蓄电池两端电压，电压表精度要求＜0.1%。

6.3.2 读取IBS输出的电压值V1并记录。

6.3.3 读取电压表此时的电压值V2并记录。

6.3.4 测试5组数据，对比V1与V2的大小，(V1-V2)/V2*100%≤±0.25%。

|序号|操作步骤|预期结果|
| ---- | ---- | ---- |

|2|使用诊断设备或对应工具，读取智能电池传感器（IBS）输出的电压值，标记为V1并记录下来|成功读取IBS输出电压V1，记录数据有效|
|3|读取步骤1中连接好的电压表显示的电压数值，标记为V2并记录下来|成功读取电压表电压V2，记录数据有效|
|4|重复步骤1-3的操作，完成5组电压数据的测量（每次测量都要确保接线、读取流程规范）|顺利获取5组V1、V2数据，每组数据完整可用于计算|
|5|对每组数据，按照公式(V1−V2)/V2×100%计算偏差，检查每组偏差是否≤0.25%|5组数据计算出的偏差均满足≤0.25%的要求|

# 6.4 电流精度测试

## 前置条件

6.4.2 读取IBS输出的电流值I1并记录。

6.4.3 读取电流表此时的电流值I2并记录。

6.4.4 调整放电电流，测试5组数据，放电电流分别按10A，20A，50A，100A，200A，对比I1和I2大小，(I1-I2)/I1*100%≤±1%。

|5|对每组数据，按照公式(I1−I2)/I1×100%计算偏差，检查每组偏差是否≤1%|5组数据计算出的偏差均满足≤1%的要求|

6.5.2 读取IBS输出的温度值T1并记录。

6.5.3 读取温度传感器的温度值T2并记录。

# 6.7 SOF精度测试

6.7.2 车辆进入起停系统后，读取并记录当前IBS输出的SOF_V1_1数据。

6.7.4 测试5组数据，对比SOF_V1_1与SOF_V1_2大小，SOF_V1_1-SOF_V1_2≤±0.5V。

# 6.9 休眠唤醒测试-低SOC唤醒（静置法）

6.9.2 检查零件的标定状态，应确认为标定状态。

6.9.3 将IBS连接器断开，等待60S后，再次插上。

6.9.4 将IBS连接到测试所用的电源上。

6.9.5 读取IBS的SOC及SOC_STATE，SOC_STATE应为未校准状态。

6.9.6 直接调整电源电压>13.5V（根据温度查表）且持续25分钟后，读取IBS的SOC及SOC_STATE信号，SOC_STATE应为校准后的状态。

6.9.7 配置低SOC唤醒的阈值和使能。

6.9.8 关闭停止LIN通讯，并检测IBS发送的唤醒帧。

6.9.9 在30min钟内不应收到IBS发送的唤醒帧。

6.9.10 调节电流源模拟将电压调整到对应的阈值SOC对应的电压下-0.2V。

6.9.11 检查IBS在5min内的唤醒帧是否发出，在收到IBS唤醒帧后，开启LIN通讯读取唤醒原因。

|3|将IBS连接器断开，等待60S后，再次插上|IBS复位|
|4|读取智能电池传感器（IBS）的剩余电量（SOC）及剩余电量状态（SOC_STATE）|SOC_STATE显示为未校准状态|
|5|直接调整电源电压>13.5V（根据温度查表）且持续25分钟后，静置后再次读取IBS的SOC及SOC_STATE信号|SOC_STATE显示为校准后的状态|
|6|配置低SOC唤醒的阈值和使能|LIN通讯无错误、且配置成功|
