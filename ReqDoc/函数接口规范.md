# 函数接口规范

本文按当前 `IBSTest` 工程登记实际接口；休眠用例步骤见 [休眠平均电流测试方案](休眠平均电流测试_VTT页面步骤.md#02-测试流程设计)。`SNAP_Write` 已删除。

## 当前可选 VTT 节点

| 节点 | 用于 | 对应实现 / 说明 |
|---|---|---|
| `PHASE_Prepare(SequenceName)` | Preparation 唯一入口 | `IBSTest.vtt`：开日志、校验基础参数、停 LIN、禁唤醒、关输出、切 IDLE |
| `PHASE_Complete()` | Completion 唯一入口 | `IBSTest.vtt`：停 LIN、关输出、等 DVM 回零、切 SAFE、禁唤醒、停日志；收尾失败汇总 |
| `PWR_Off_Check()` | body；Preparation / Completion 内部 | 调 `PWR_Off()`；发命令不等于输出物理确认 |
| `PWR_Configure_Check(V, Ichg, Idchg)` | body | 调 `PWR_Configure`；电压单位 V，限流单位 A |
| `PWR_On_Check()` | body | 调 `PWR_On()`；到压另查 DVM |
| `LIN_OpenNormal_Check()` | body | 调 `LIN_OpenNormal()`；等帧不等于完成后续 10 s 监控 |
| `LIN_Stop_Check()` | body；Preparation / Completion 内部 | 调 `LIN_Stop()` |
| `SleepCurrent_Run()` | `SleepCurrentTest` 测试执行 | 10–14 V × 3 轮，DVM 到压、LIN 监控、CAB1500 积分及平均电流判定；实现位于 `IBSFunctions.can` |
| `PHASE_ValidateParams_Check()`、`SNAP_WakeNode_Off_Check()`、`RELAY_Set_IDLE_Check()` | Preparation 内部 | 基础参数校验、禁唤醒、切 IDLE |
| `PHASE_Complete_Begin_Check()`、`PWR_WaitZero_Check()`、`RELAY_Set_SAFE_Check()`、`PHASE_Complete_Result_Check()` | Completion 内部 | 清理状态、回零、切 SAFE、汇总清理失败 |

以上 `*_Check` 均定义在 [IBSFunctions.can](../IBSTest/IBSFunctions.can)；`PHASE_*` 及 `StartLog` / `StopLog` 定义在 [IBSTest.vtt](../IBSTest/IBSTest.vtt)。其中 `RELAY_Set` 仅下发命令，无独立触点回读；其他命令也不得当作设备物理确认。底层 CAPL 函数不要直接填进 VTT 页面调用栏。

## 运行前提

`SleepCurrent_Run()` 已在 vTESTstudio 4.0.64.0 编译通过；它直接调用同一 CAPL 文件中的底层电源/LIN 函数，并通过 `IBS_LIN::StaticCurrent_*` 控制 CANoe 中的 CAB1500 积分节点，不调用旧 `StaticCurrentAtVoltage`。参数组“休眠平均电流测试”的两个限流默认 0 A，运行前须按台架确认值设为正数。外部 CAB1500 脚本是否加载及设备实际响应仍未验证。
